Agents tab

Opened deliberately (click on the notch, then ⌘2), so the panel holds keyboard focus: ↑↓ moves the selection, ↵ focuses that session's terminal tab, Esc closes. Blocked and failed sessions sort first, most recent first. The elapsed time keeps counting after the alert. Focus is the only action. Vigie never answers an agent for you. The Terminal column appears only when sessions span more than one terminal app.
