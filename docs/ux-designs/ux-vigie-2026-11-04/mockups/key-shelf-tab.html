Shelf tab

Shown

  • 01 Main: 5 stashed items (name, size, mode ref / copy / saved, source app, added time, time left of a 7-day TTL, drag grip). The hovered row shows its actions and the drag-out hint: DRAG · MOVE ⌥ DRAG · COPY. Ask AI shows the default agent and folder and the ⌥ alternate.
  • 02 Drag-hover: a stash item dragged onto Ask AI with ⌥ held. Empty stash.
  • 03 Home shelf widget with the expiry warning, dark and light.

Notes

  • Drops from other apps land on the closed notch (EXPERIENCE Interaction Primitives). This tab's Ask AI only receives drags that start inside the panel, from a stash item.
  • Time context: Wed 04 Nov 14:48, TTL set to 7 days. Time left = added time + TTL − now.
  • Two different ⌥ meanings: dragging out of the stash, ⌥ = copy (Finder). Dropping on Ask AI, ⌥ = alternate folder (memlog).

Composition choices to confirm

  • Layout: Stash as a dense table card (left), Ask AI as a 212px card (right) holding the zone and its settings readout.
  • Internal drag: a stash item can be dragged onto Ask AI inside the expanded view. This adds a drop target that is not on the closed notch.
  • Time-left format: 6D LEFT at 2 days or more, 1D 18H LEFT under 2 days, EXPIRES IN 5H under 24 h. Thin metal bar for the fraction of TTL left.
  • Expiry warning: starts 24 h before expiry. Uses the working hue (DESIGN: working doubles as the warning hue) plus a small triangle, so it does not rely on colour alone. Shown on the row, in the card meta (1 EXPIRING) and on the Home widget (5H tag + 1 EXPIRES IN 5H). No alert and no sound.
  • Mode tag in each row's meta line (ref / copy / saved): it tells the user what expiry will do. The footnote states the rule.
  • Hover actions: QUICK LOOK · REVEAL · PIN chips replace the source and added columns. A tooltip over the grip shows the move/copy hint. The footer repeats it.
  • Pinned: dashed lilac line and PINNED in place of the time left.
  • Drag-hover: solid lilac border with an inner tint. The label changes to RELEASE TO ASK and names the target. With ⌥ held, the default folder dims and the ⌥ row lights up. The drag ghost carries an ⌥ badge.
