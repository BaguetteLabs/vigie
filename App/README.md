# App

Thin Xcode app target (AD-2): assembly code, Info.plist, InfoPlist String Catalog, entitlements and assets only. All other code lives in `../Packages`.

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is not committed:

```sh
cd App
xcodegen generate
xcodebuild -project Vigie.xcodeproj -scheme Vigie -configuration Debug build
```

Debug builds are `Vigie Dev.app` (`fr.baguettelabs.vigie.dev`); Release builds are `Vigie.app` (`fr.baguettelabs.vigie`). Both are ad-hoc signed for now.
